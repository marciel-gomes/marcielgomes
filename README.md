# Currículo interativo — Marciel Gomes

Este repositório contém um currículo interativo, em português, de Marciel Alberto Gomes, Engenheiro de Dados Sênior e Analytics Engineer. A página apresenta sua trajetória profissional, formação, competências e resultados de forma responsiva e acessível.

## Conteúdo

- `index.html` — página principal, com estilos e interações incluídos no próprio arquivo.
- `samples/MarcielGomes_DE_112026_pt.pdf` — currículo original em PDF.

## Recursos

- Layout adaptável para dispositivos móveis e desktops.
- Filtros para explorar as competências por categoria.
- Alternância entre temas claro e escuro, com preferência salva no navegador.
- Experiências profissionais com detalhes expansíveis.
- Links para contato, LinkedIn, WhatsApp e currículo em PDF.
- Estilos específicos para impressão.

## Publicação no GitHub Pages

Para publicar, envie este repositório ao GitHub e, nas configurações do repositório, habilite o GitHub Pages usando a branch e a pasta que contêm `index.html`. Mantenha o PDF no caminho `samples/MarcielGomes_DE_112026_pt.pdf` para que os links para o currículo continuem funcionando.
